# AgentBot

本地运行的**多智能体协作工作台**。每个智能体有自己的长期记忆、自己的职责，可以在群里协作、私聊干活、互相传话。

```
┌──────────┬──────────────────────────────┬──────────────┐
│ 白泽联调  │  @everyone 各说一句…          │ 屏幕/记忆/成员│
│ 测试运维  │  ┌─ 测试运维 ──────────┐      │              │
│ 知识库服务│  │ 159 的 checklist…   │      │ 群：成员表    │
│ 白泽团队  │  └────────────────────┘      │ 私聊：记忆    │
│ AI服务   │  · 白泽团队 看过，没开口       │ 三层×三作用域 │
│          │  ┌ 发消息…              → │     │              │
└──────────┴──────────────────────────────┴──────────────┘
```

## 快速开始

```bash
npm install && npm --prefix web install && npm --prefix desktop install

cp .env.example .env    # 填入 AGENT_API_KEY（源码里不含密钥）
npm run desktop         # 桌面客户端（内置后端，推荐）
```

其它入口：

```bash
npm run server      # 后端 + 网页 http://127.0.0.1:8787
npm run web:dev     # 前端热重载 :5173
npm run dev -- "读一下 package.json"    # 命令行模式
```

## 核心特性

- **每个智能体一本笔记** —— 不是全产品一份用户档案
- **群是广播不是中心 AI** —— 一条消息扇出给全体成员，各自决定说还是不说；沉默是一等公民
- **上下文 ≠ 消息历史** —— 每轮重新组装七段（画像 / 关于你 / 日志 / 随手 / 检索 / 摘要 / 近期原文）
- **记忆永不报错** —— 画像满了降级成日志，日志老化移出眼前，随手笔记自动过期
- **零运行时依赖** —— 手写 HTTP/SSE、手写存储，只用 Node 原生能力
