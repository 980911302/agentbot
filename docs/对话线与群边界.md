# 对话线与群边界

整理日期：2026-09-15

每个智能体只有**一条**对话线。私聊和它进过的群回合都记在自己身上。进群时带着私聊里学到的事，是预期行为，不是串台。

群不是另一个记忆库，也不存别人的私聊。本文写这条线怎么用、进群能带什么、不能带什么。记忆分层见 `架构设计.md` §0.1、§8，点名见 `群聊点名.md`。

---

## 1. 记在谁身上

| 记什么 | 记在哪 | 谁读得到 |
| --- | --- | --- |
| 主人跟 A 的私聊 | A 的对话线 | 只有 A（和主人打开 A 的界面） |
| 某群里 A 看见的话、A 自己说的话 | A 的对话线 + 该群时间线 | A 读自己的线；群界面读时间线 |
| 主人跟 B 的私聊 | B 的对话线 | A 读不到，也不该去翻 |
| 群公开历史 | 群时间线 | 当时在场的人；**入群前的没有** |

长期记忆（画像 / 日志 / 随手）也是按智能体分的，不是按群分的。群话值不值得进记忆，由抽取决定，默认多数进不了。

所以：A 在群里「还记得你刚才在私聊里让我盯 159」，这是 A 用自己的线，正常。A 说「B 刚才私下跟你说了数据库密码」，这是越界。

统一对话线不是“待汇报事项清单”。历史只在和当前群消息相关时使用；社交交流只按当前意图回应，不能因为历史里有未完工作便主动复述、续做或派工。

---

## 2. 进群允许带什么

预期：

- 用私聊里**已经达成的结论、事实、决定**答群。
- 用自己的长期记忆、自己做过的工具结果。
- 主人没说保密的工作上下文：分支、环境、谁负责什么。

例如：

```
私聊：主人让测试运维今晚发 159，分支 zll-dev。
群里主人：@测试运维 今晚还发吗
测试运维：发。159，zll-dev，我来推。
```

这是同一条线上的连续工作，不是泄密。

---

## 3. 进群禁止带什么

| 禁止 | 原因 |
| --- | --- |
| 把私聊原文整段贴进群 | 群里人人可见；原文常带抱怨、密钥、未说完的草稿 |
| 复述「你刚才跟我说……」再加引号大段 | 和贴原文一样 |
| 主人明确说「这个别带进群 / 先别让他们知道」 | 用户划的边界，高于「统一历史」 |
| 提其他同事与主人的私聊，或假装读过 | 那些不在自己的线上 |
| 去翻同事的 messages、记忆、文件 | 没有这个工具，也不该装有 |

拿不准一段私聊能不能进群：用 `SendToUser` 的 `to:"dm"` 问主人，或在群里只说自己职责内、已公开的那一句。

密钥、选项卡、附件本来就进不了群，走 dm。结论改口成字可以进群，原文凭证不行。

## 4. 模型实际看见什么

平台：一条对话线，群回合用房间标签标出来。读到的「最近原文」里，私聊和群回合按时间排在一起。群简报只补本轮房间上下文，不把私聊抹掉。

技能原文语义：

```
用你统一历史上知道的事答群（包括私聊里学到的）是预期行为。
用户明确说不要带进群的除外。
不要去翻同事的私聊、记忆或文件。
```

AgentBot 现在把群消息也 `append` 进该成员自己的 `messages`，模型更容易看见私聊原文。这没写错，但更容易「贴原话」。要靠简报压住，不要再给每人复制一份私聊进群上下文。

私聊 UI 已经过滤群经验：`privateConversationMessages` 丢掉带 `roomId` 或 `source === 'room'` 的记录。同一条群消息只在群面板出现一次，不会再渲染成该成员发给主人的私聊。

---

## 5. 简报加一句（推荐）

`ROOM_SKILL` / `buildRoomBrief` 里固定加上：

```
- 可以用自己私聊和记忆里的结论答群；不要粘贴私聊原文，不要提主人跟别的同事的私聊。
- 主人说过不要带进群的事，就不要带。
```

不要写进每个同事的 `instructions`。进群再注入。

1:1 同事来信简报保持原样：回同事用 `SendToAgent`；要让主人知道的新结果再 `SendToUser`。不要把同事来信当群话广播。

## 6. 界面和落盘

- 主人打开 A：看见自己跟 A 的私聊，以及 A 参与过的群回合（带房间标签）。这是同一条线的两种显示，不是两份记忆。
- 群界面：只渲染该群时间线。不要把 A 的私聊气泡画进群里。
- 新成员：时间线从入群后开始，也不继承别人私聊。
- 抽取记忆：群里随口一句默认不进画像；跨群都成立的事实（主人时区、环境分工）可以进 `user` 画像。

---

## 7. 和「串台」怎么区分

| 现象 | 判 |
| --- | --- |
| 私聊定了发 159，群里它按这个答 | 正常 |
| 群里贴出私聊逐字记录 | 错，简报没压住或模型没守 |
| 群里提到 B 跟主人的私聊内容 | 错，越权 |
| 两个智能体职责写反、互相冒充 | 错，身份层，不是对话线问题 |
| 没被 @ 却把私聊结论当众复述一遍凑热闹 | 多半不该开口，见 `群聊点名.md` |

第一条不要修成「进群清空私聊上下文」。那会让它失忆。要修的是出口纪律。

---

## 8. 完成标准

1. 同一智能体的 `messages` 按时间混合私聊与群回合；群记录带 `roomId`。
2. 群时间线不含任何 `source=dm` / 私聊原文。
3. 群简报含「用结论、不贴原文、不提他人私聊」。
4. 智能体没有读取其他 `agentId` 的 messages/记忆的工具。
5. 主人说「这个别带进群」之后，抽取应能记一条自己的随手/日志；单测至少保证这句话还在它自己的线上。
6. 新成员入群后的第一次回合，上下文里没有入群前的群历史，也没有其他成员的私聊。

单测断言落盘和简报文案，不要靠模型「看起来没泄密」。
