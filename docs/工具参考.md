# AgentBot 当前工具参考

更新：2026-09-13。依据 `src/server/tools.ts`、`src/server/runtime.ts` 与 `src/tools/limits.ts`。本文记录本项目实际实现，不把外部平台的工具目录当作已上线能力。逐工具限额及测试见 [工具边界审计](工具边界审计.md)。

装配完整且联网开启时，当前工具定义共 24 个。具体智能体可用项由 toolNames 过滤，联网关闭时不装 WebSearch/WebFetch。运行时目录可从 `GET /api/health` 获取；该目录表示全局工具定义，不代表每位同事都有同样的授权。

## 1. 当前工具表

`*` 表示必填；参数的最终契约以源码 schema 和执行校验为准。

| 工具 | 主要参数 | 当前行为 |
| --- | --- | --- |
| SendToUser | type*、content、url、to、end_turn、widget、secret | 文本、工作区文件交付、选项卡、密钥框 |
| Read | path*、offset、limit、column | 流式分段读文本；默认 200 行，最多 500 行/12000 字符；长行可按 column 续读 |
| ListFiles | path、offset、limit | 分页列文件，默认 50 条；跳过隐藏、依赖、构建目录及符号链接 |
| SearchFiles | query*、path、offset、limit | 有扫描预算的字面文本搜索；默认 30 条，路径/行号/预览 |
| Write | path*、content*、overwrite、append | 每次最多 32000 字符，默认新建；显式覆盖/分块追加 |
| Edit | path*、old_text*、new_text*、expected_sha256 | 唯一精确匹配替换，可校验版本；不回显源码 |
| Shell | command*、working_directory、block_until_ms、timeout_ms、description | 本机命令执行；默认等待 30 秒，0 立即转后台；默认运行上限 10 分钟 |
| AwaitShell | shell_id、block_until_ms、pattern、offset、stop | 增量读日志；pattern 为字面文本，不是正则；stop 杀进程组 |
| ReadToolOutput | output_id*、offset、limit、query | 持久原文分页/字面搜索；UTF-8 字节游标；只能读自己的日志 |
| RecallMemory | query*、scope、limit、offset、full | 默认预览，full=true 返回最多 4 条完整原文，支持分页 |
| update_state | target*、action*；各目标附加参数 | 修改自己的记忆、资料、隐藏状态、头像、项目归属 |
| ListSections | offset、limit | 分页列分组名称（当前名称即 section_id），默认 20 条 |
| CreateAgent | name*、description、section_id | 创建持久同事；description 转为职责；每回合最多建 2 个 |
| UpdateAgent | agent_id*、name、description | 修改同事名字/职责；未给字段保留，空值不覆盖 |
| CreateChannel | name*、member_ids* | 建群，1–6 位有效同事；每回合最多建 1 个 |
| UpdateChannel | channel_id*、add_member_ids、remove_member_ids | 增减群成员；调用者必须已在群中；不能删空 |
| SendToAgent | target_id*、message*、images、priority | 给同事或所在群传话；可按稳定 ID 或名字解析，优先用 ID |
| WebSearch | search_term*、explanation | 公网搜索，返回标题/URL/摘要；不是登录态服务查询 |
| WebFetch | url*、secretName、maxChars、offset | 公网文本分页，正文默认最多 12000 字符；逐跳检查及连接时 DNS 校验 |
| Task | description*、prompt*、subagent_type*、run_in_background | 只支持 executor；前台最多等 30 秒，之后后台；单次最长 10 分钟 |
| CheckSubagent | subagent_id、offset、limit | 只能看自己派出的工人；列表默认 20 条，保留完整 ID |
| MessageSubagent | subagent_id*、message* | 给工人排入纠偏消息；当前执行中的接收时机仍需核验 |
| StopSubagent | subagent_id* | 取消工人，使用其当前中止句柄 |
| TodoWrite | todos*、merge* | 按 agent 持久保存；重写至少 2 条，合并可 1 条，总量 ≤100 条 |

## 2. SendToUser 的四种输入

| type | 必要内容 | 路由与限制 |
| --- | --- | --- |
| text | content | 私聊写入同事对话线；群里默认写入群 posts，to=dm 私发主人；群每回合上限 3 条 |
| attachment | url | 工作区内已有文件路径，可带 file://；复制到允许交付目录并写一条交付位置消息；群回合须用 to=dm |
| widget | widget.prompt、widget.options | 选项至少 2 个，每个含 label，可给 value；支持 helpText；multiSelect=true 当前报错；群回合须用 to=dm |
| secret-request | secret.name；可选 label/description | 弹遮罩输入，值进入 SecretStore，工具结果只返回密钥名字；群回合须用 to=dm |

产品提示把 SendToUser 定义为私聊与群聊的统一出口。考虑到部分模型偶尔不会发起工具调用，私聊在“整轮完全没有调用 SendToUser”时会把最终正文作为兼容兜底；该正文不提前流式展示。一旦调用过出口，就不会再追加普通助手文本。群回合没有该兜底，只认工具写入的 posts。

`end_turn=true` 会标记当前回合并让 AgentLoop 在该次出口完成后立即收尾，不再额外请求一次模型。widget 强校验 2–6 个选项及唯一 ID；multiSelect=true 会拒绝，allowCustom=false 当前不支持，会明确拒绝。

附件是文件交付能力，不等于图片上传、内联预览、消息附件寻址已经齐全。不得调用 attachment 传 https 地址后宣称远程图片已保存。

## 3. update_state 子集

| target/action | 字段 | 已实现范围 |
| --- | --- | --- |
| memory/write | fact、tier=profile/log/note、scope=agent/user/project、project | profile/log/note 映射 portrait/log/scratch；项目须显式给归属 |
| memory/forget | fact 原文、scope、project | 按完整原文精确删除；不确定时先 RecallMemory |
| profile/set | name、description、title、avatar_color | description 写入 instructions；此处不是独立长简介字段 |
| settings/set | hidden_from_sidebar | 只支持隐藏；通知开关尚未接入 |
| avatar/set | path | 检查已有文件及大小 <5 MB，保存路径；图片展示/上传链路尚待补齐 |
| avatar/clear | 无 | registry 已允许显式清除头像，不影响其它字段的空值保护 |
| project/join、leave | project | 修改 projectIds；不创建独立项目对象 |

routine、skill、channel 目标当前明确报“暂不支持”；project/create 尚不支持。不要因为参数名来自平台清单，就把对应子系统写成已完成。

## 4. 协作与后台任务

SendToAgent 给同事写入收件箱和双向往来档案；给群写时间线、成员经历并逐个入队。两种发送都不等待模型执行，返回固定短句，回信属于之后的新回合。收件人不是发送者的子任务，停止发送者不会撤回消息或停止同事。priority 对同事表示队列优先，群忽略，不会打断正在进行的用户回合。

images 仅限 1:1，最多 4 张 HTTP(S) URL，每个地址最多 2048 字符、alt 最多 300 字符；不接受本地路径/base64，群图明确拒绝。图片贯通至视觉模型的 image_url 内容块，不将文字说明冒充图片；模型是否支持识图由供应商决定。同群内用 SendToUser 即时发言，不允许 SendToAgent 再次广播唤醒整组；私发和跨群保留传话深度。目标先按 id，再按名字回退；同名歧义列出可选 id，群名称候选仅限调用者所在群。

Task 工人没有用户完整对话上下文，prompt 要包含目标、背景、约束、交付标准。worker_id 与固定 agentId 不同。运行时注入 dataDir 时，worker/Todo 身份与状态持久化；重启不自动重放可能含副作用的旧工作。Task 的 resume、file_attachments、videoReview/watchVideo/computerUse 未在当前 schema 实现。

纠偏在工人当前一段工作结束后消费，最多积压 8 条/32000 字符；已结束的可再次发消息续跑。工人不能再次 Task、创建同事/群或 SendToAgent；停止/超时会取消模型和登记的 Shell。工人每次具体操作进入 ToolInvocation 账本。轮数/工具配额耗尽为 incomplete，异常为 failed，超时为 timed_out，重启中断为 interrupted；不再统称 done。done 仅表示工人已答复，不代表独立验收通过。

## 第一批可靠性基础

工具执行器使用结构化 `ToolResult`，保留文本 `execute` 兼容接口。消息仍保留原来的 result/ok，新增可选 outcome 元数据。原文以 `Error:` 开头不会被判失败；自定义工具应抛异常或返回 `toolError(code, message)`。

Shell 原文自动保存；其他工具结果超过可见额度时也落盘。默认单日志 32MiB、总正文 256MiB、最多 1000 条，关闭日志保留 7 天（触发读写或重启时清理；配额不足可提前清理旧关闭日志）。活跃日志不清理；无法继续保存时显式标记 storageTruncated，不宣称原文完整。ReadToolOutput 默认读 8000、最多 12000 字节；搜索每次扫描最多 256KiB、返回最多 30 个位置。AwaitShell 保留旧字符游标，不能与 ReadToolOutput 的字节游标混用。

每次运行保存独立任务快照，记录原目标、已读/已改文件、待办、近期执行证据、未决工具调用和阶段交接；已停止快照全局最多保留 500 个，完整历史另存。刚停止的任务可在私聊明确说“继续”，或通过发送接口的 resumeTaskId 精确选择；普通新任务不自动关联。GET /api/agents/:id/tasks 返回分页摘要，GET /api/agents/:id/tasks/:taskId 返回完整快照。恢复只带回证据，不自动重放工具或回滚文件；仍须核对实际产物。轮数/工具总配额用尽不会自动续跑。详见 [第一批可靠性说明](第一批可靠性.md)。

## 5. 文件、网络与数据边界

- Read 使用本机文件路径，不限制在项目根；仅文本。大于 256KiB 也能分段读，扫描量最多 32MiB；每行最多返回 2000 字符，可按 column 续读。
- Shell 在本机运行，工作目录需有效；它不是云电脑。执行器需负责进程生命周期、超时、输出截断和取消，恢复时未知动作必须核对。
- SendToUser 附件允许工作区文件或已经处于交付目录中的文件；校验 realpath，最多 50MiB，重名不覆盖。目录白名单由 AGENT_DELIVER_DIRS 配置。该约束不等同于整个 Shell/Read 都有同样边界。
- WebFetch 的内网与协议检查在 web.ts；失败应区分网络、超时、格式和访问边界，不伪造已读页面。
- 共用用户笔记不是其他同事私聊的读取入口；项目笔记只能在当前可见项目范围内使用。
- SecretStore 不把值放进普通工具结果和消息。后续设置/连接器统一引用密钥名称，敏感值不复制到工作摘要。

## 6. 后续工具能力及归宿

| 能力族 | 目标 | 执行计划 |
| --- | --- | --- |
| 资料/头像/分组/项目/通知 | 完善 update_state、ListSections 与 UI 一致性 | E5 |
| 例程、技能 | CRUD、暂停恢复、定时/事件触发、按需加载技能正文 | E6 |
| 动态工具 | 发现 schema、命名空间、能力启用、工具调用与账本集成 | E7.1 |
| 插件生命周期 | SearchPlugins/GetPlugin、安装卸载、状态/授权、自定义 MCP、账号命名/移除、连接器说明、重连 | E7.1 |
| 外部消息与草稿 | DraftExternalMessage、已解析收件人和线程、发送幂等 | E7.2/E7.3 |
| 生图 | GenerateImage：描述、比例、参考图、实际文件交付 | E7.4 |
| 表单、图片/PDF、视频理解与复核 | 合适的读取/生成服务，明确费用和支持范围 | E7.5 |
| 模板、表情、反馈 | 去隐私导出/导入、ReactToMessage、明确的反馈提交 | E7.6/E7.7 |

插件安装和外部发送遵循用户明确授权与产品交互要求；不能把宿主工具中的规则或账号状态当成 AgentBot 已具备的能力。连接器自有工具由插件注入，避免在 Runtime 写死服务商。

云电脑、注册机器和跨机器复制不在范围。CloudAgent/request_scm_connect 等云端仓库代理属于待定扩展，不能为了补平台数字而实现。当前不以“凑齐 46 个工具”为验收标准，以用户流程和工具真实行为一致为准。

## 7. 维护规则

新增或修改工具时同步源码 schema、执行校验、工具参考及对应行为测试。若工具只是包装一个服务，测试重点是参数转换、权限和失败返回；实际生命周期在服务集成测试覆盖。

未来从同一工具注册表生成列表和参数骨架，人工只维护限制与产品语义。工具名称兼容性单独迁移，代码模块重命名不随意改变模型可调用名称。
