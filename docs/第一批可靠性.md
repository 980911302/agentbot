# 第一批：执行结果、日志与任务恢复

实现日期：2026-09-13。只补可靠性基础，不包含工具并发、批量编辑、浏览器验收、独立目标验证、用量统计或无限续跑。

## 结果协议

- `ToolRegistry.executeResult` 是执行器入口：status/content/error/output/execution/task 分离。
- `defineTool` 接受文本或结构化结果；返回的 execute 继续提供文本接口，executeResult 提供结构化接口。旧的成功文本原样保留；失败应抛异常或返回 toolError，不再使用 Error: 前缀充当状态。
- 消息和工具账本增加可选 outcome 元数据，旧 JSONL 可继续读取；模型仍收到有界文本，前端原展示字段不变。
- 后台 Shell 的 running 不是完成，exit 非零/取消/超时/重启中断分别返回。CheckSubagent 查询成功与工人任务状态分开。
- 运行 `final_answer` 表示已答复；`max_iterations`/`tool_limit` 表示 incomplete。工人异常不能标 done，独立验收仍属于第二批。

## 持久日志

位置为 dataDir/tools/outputs，正文和元信息独立保存，文件权限 0600。

Shell 的 stdout/stderr 按接收顺序合并保存；其他工具在可见结果超限时保存完整返回文本。读取通过 output_id 而不是任意文件路径。拥有者以 agentId 隔离；后台工人日志属于该工人。

默认每条 32MiB、总正文 256MiB、最多 1000 条日志。关闭日志默认保留 7 天，读写/启动时惰性清理，配额不足时提前清理最旧的关闭日志；不清理活跃日志。达到配额后保存连续前缀，storageTruncated=true，同时保留 totalBytes/retainedBytes；磁盘写入失败会明确报出。日志配额不表示无限存储。

ReadToolOutput 默认返回 8000 字节，最多 12000 字节，游标为 UTF-8 字节；按 next_offset 续读不切断多字节字符。字面搜索每次扫描最多 256KiB，最多 30 个命中，命中位置可以用于读取。AwaitShell 为兼容旧调用继续使用字符游标，两类游标不可混用。

重启将未关闭的 Shell 记录标记 interrupted，允许查原文和状态，但不重新启动进程、不操作已失效的旧 pid。它不能证明旧进程已退出；恢复时需核对外部状态。

## 任务检查点与恢复

位置为 dataDir/tasks/progress，每次运行独立快照。工具执行前记录意图，执行后记录状态、输出标识和命令退出信息；保存目标、最近读/改文件、TodoWrite 待办、阶段交接。未知调用不会被当成成功或自动重放。

检查点保存最近 24 条工具证据、各 60 个读/改文件路径、100 条待办；模型恢复简报最多 24000 字符，详细历史仍在消息/工具账本中。已停止快照全局最多保留 500 个，运行中不裁剪。检查点不是 Git 快照，不会回滚用户文件。Shell 引发的文件变化不凭命令名推断为已修改文件，需结合命令证据和实际文件核对。

使用方式：

1. 私聊刚停止的任务，发送“继续”“继续上个任务”“继续刚才的任务”“接着做”或“恢复上个任务”。仅关联当前私聊最近的未完成/失败/中断/取消任务；普通新任务不自动续接。
2. `GET /api/agents/:id/tasks?offset=0` 分页查看摘要，每页 20 条。
3. `GET /api/agents/:id/tasks/:taskId` 获取完整快照。
4. 原有 `/api/chat` 或 `/api/agents/:id/messages` 发送接口可增加 `resumeTaskId`，text 仍必填；拒绝其他智能体的任务以及仍在运行的任务。
5. 工人停止后用 MessageSubagent 明确续跑，带回该工人的最近任务快照。

恢复快照作为历史数据注入，不提升为 system 指令，不覆盖最新用户要求。轮数/工具额度用尽不会自动开下一轮；原有插话 parked 的有限恢复机制仍保留。工具意图无法持久化时阻止该调用；记录为 unknown 的调用不会被账本保留上限误裁掉。

## 验证范围

新增离线测试覆盖结构化状态、Error: 正文、输出超限落盘、UTF-8 分页、跨扫描边界搜索、owner 隔离、磁盘配额、真实本机 Shell 非零退出/取消/超时、大日志、重启状态、任务中断快照、显式续跑、避免重复写文件和后台工人停止原因。

测试不调用付费模型，不代表已完成真实模型端到端或浏览器验收。新任务从更新后的服务进程开始获得这些检查点；历史上已经丢弃的日志无法补回。
