## 1. 一条私聊消息的一生（含流式）

```
用户回车
  → POST /api/chat (SSE 打开)
  → runtime.send → runTurn
      用户消息先落库 → (可能触发压缩) → 组装七段上下文
      → AgentLoop: provider.chat(stream:true)
            ╎← delta:"你"  delta:"好" …      ← 60s 无字节=看门狗报错→可重试
      → 完整文本落库, emit message            ← 前端清空 liveText,落正式气泡
      → 有工具调用? ─ 是 → 执行→结果落库→下一轮（循环）
      │              └ 否 → final
  → 记忆抽取 → done
  → SSE 关闭
界面: delta→打字机气泡 │ message→applyEvent 折叠进消息流 │ 工具调用→「屏幕」时间线
```

## 2. 一次群消息的一生（扇出，无中心 AI）

```
用户在群里说话（可 @名字 / @everyone）
  → POST /api/rooms/:id/messages
  → 写房间时间线 + 并行写每个成员自己的对话线（群和私聊是同一条对话线）
  → 波次1 被点名者 串行（必须开口; say 工具=发言, 收尾文本兜底）
  → 波次2 在场未点名 并行（互相看不见本轮; 默认沉默,沉默=一等公民）
  → 波次3 被同事发言 @ 到的人 串行（二次叫醒, 每人每轮≤2次）
  → fanout_done(spoke/silent 计数)
界面: round_start→该成员头像气泡"正在回复…" │ room_message→落消息流
      round_end(未开口)→"看过,没开口"轻提示 │ ask_user 卡片照常可弹可答
```

## 3. 事件协议（SSE 载荷）

| 通道 | 事件 | 前端反应 |
| --- | --- | --- |
| `event:` | `delta{text}` | liveText 打字机（仅私聊） |
| `event:` | `message{...}` | 气泡落位 / 工具调用进时间线数据 |
| `event:` | `interaction{request}` | 问答卡片 + 后台时系统通知 |
| `event:` | `context/iteration/compacted/memory/final` | 忽略或轻提示 |
| `room:` | `room_message / round_start / round_end / fanout_done` | 消息流 / 成员气泡 / 沉默提示 |
| `done:` / `error:` | 终态 | busy 复位 / 错误气泡(可重试) |
| `: ping` | 15s | 保活（前端忽略） |
